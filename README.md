This project is a replica of a store website based on a design provided on Figma. The goal was to accurately convert a UI design into a fully functional and responsive website.
I carefully followed the design specifications, including layout, typography, spacing, and color scheme, to achieve a pixel-perfect result. Along with replicating the original design, I also enhanced the project by adding extra sections and improving overall user experience.
The website was built from scratch using HTML, CSS, and JavaScript, with a strong focus on clean structure and responsiveness across different devices.

Key Highlights :

1. Pixel-perfect implementation of Figma design
2. Added custom sections beyond the original design
3. Fully responsive (mobile + desktop)
4. Clean and structured code
5. Focus on UI/UX consistency

Purpose :

1. This project helped strengthen my ability to:
2. Convert designs into real-world websites
3. Understand spacing, alignment, and layout deeply
4. Build responsive and user-friendly interfaces
